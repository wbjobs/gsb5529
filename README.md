# 一致性哈希环可视化工具

纯前端实现，无构建步骤。技术栈：Canvas + Web Worker + Web Crypto（SHA-256）+ IndexedDB。

## 运行

需要通过 HTTP 访问（Web Worker 不支持 `file://`）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 功能

- **双模式对比**：左侧无虚拟节点环，右侧虚拟节点环（1–500 可调），同一组节点/键实时对比。
- **节点管理**：添加/删除节点，自动着色，实时显示每节点键数。
- **键管理**：单个添加/删除、批量随机添加、清空；点击键可在两个环上高亮，悬停环上的点显示归属。
- **最小迁移**：增删节点时只迁移必要键，迁移键在环上以黄圈标出，并与传统取模哈希的迁移量对照。
- **均衡度量化**：变异系数 CV（0 为完美均衡）、标准差、最大/最小比、每节点柱状图 + 理想均值虚线。
- **哈希冲突**：SHA-256 截断为 32 位位置，冲突时自动检测、记录并线性探测避让，在冲突面板中展示。
- **边界情况**：空环（键显示未分配、环虚线提示）、单节点（全部键归它）均正常。
- **持久化**：节点、键、虚拟节点数自动保存到 IndexedDB，刷新自动恢复。

## 实现说明

- `js/hashring.js` — 核心逻辑（环境无关，主线程/Worker/Node 测试共用）：SHA-256 哈希、环构建、二分查找后继、归属、均衡度统计、迁移 diff、取模哈希对照。
- `js/worker.js` — 在 Worker 中执行全部哈希与环计算，不阻塞 UI。
- `js/viz.js` — Canvas 绘制环、键分布、迁移高亮、均衡度柱状图。
- `js/db.js` — IndexedDB 读写。
- `js/app.js` — 状态管理、渲染调度、事件、持久化。
- 虚拟节点编号为 `节点id#序号`（如 `node-A#0`），无虚拟节点模式直接哈希节点 id。

## 测试

```bash
node test/ring.test.mjs
```

覆盖验收标准：最小迁移（加节点只迁入新节点、删节点只迁出被删节点、迁移量 ≈ 1/N）、
虚拟节点越多 CV 越低、冲突检测与避让、空环/单节点、虚拟节点编号、归属正确性。
