# 一致性哈希环可视化工具

Canvas + Web Worker + Web Crypto (SHA-256) + IndexedDB 实现的一致性哈希环可视化与对比工具。

## 运行

需要通过 HTTP 服务访问（ES Module 和 Web Worker 不支持 file://）：

```bash
cd hashring-viz
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 功能

- **节点管理**：添加/删除节点（支持自定义名称），节点以彩色圆点显示在环上
- **键管理**：添加/删除单个键、批量生成 100 个随机键、清空；点击键可在环上高亮并连线到归属节点
- **虚拟节点**：滑块配置每节点虚拟节点数（1–500），虚拟节点以 `nodeId#i` 编号上环，显示为小方块
- **双模式对比**：左右两个环实时对比「带虚拟节点」与「无虚拟节点」的分布与迁移
- **键归属**：悬停任意键/节点显示哈希值、环上位置、归属节点
- **迁移统计**：增删节点时高亮迁移的键（金色描边 4 秒），并给出实际迁移比例 vs 理论最小比例
- **均衡度量化**：变异系数 CV、标准差、Max/Min、每节点键数与占比条形图
- **哈希冲突检测**：自动检测环上点与键的 uint32 位置冲突并列出
- **持久化**：节点、键、虚拟节点配置自动保存到 IndexedDB，刷新后恢复

## 技术要点

- 环空间为 uint32（0 ~ 2³²-1），位置取 SHA-256 摘要前 4 字节（大端）
- 所有哈希计算在 Web Worker 中批量完成，带缓存，不阻塞 UI
- 键归属 = 顺时针第一个环点（二分查找，O(log n)）
- 迁移 = 新旧归属 Map 的 diff，一致性哈希保证只迁移必要键


## 验收标准对应

| 标准 | 实现 |
| --- | --- |
| 增删节点只迁移必要键 | `diffAssignments` + 测试验证迁移比例 ≈ 1/(n±1) 且方向正确 |
| 虚拟节点越多越均衡 | CV 随 vnode 数下降（测试：1→200 时 0.54→0.06） |
| 哈希冲突可检测 | `buildRing` 冲突分组 + 键位置冲突检测，页面展示 |
| 空环/单节点不崩 | 空环归属为 null、统计为 N/A；单节点 CV=0，均有测试 |
| 均衡度可量化 | CV / 标准差 / Max-Min 比 / 占比表 |
| 环可视化准确 | 位置 = hash/2³² 角度映射，悬停可验证 hash 与位置 |
| 配置持久化 | IndexedDB 保存节点/键/vnode 配置 |
